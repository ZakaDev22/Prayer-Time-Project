# 🕌 Moroccan Cities Prayer Times — Web App

A modern and simple **Prayer Time Application** for Moroccan cities that helps you quickly check daily and monthly prayer times for **Fajr, Dhuhr, Asr, Maghrib, and Isha**.

---

## 🌐 Live Demo

👉 [Check it here!](https://zakadev22.github.io/Prayer-Time-Project/)

---

## 📌 Features

- 🇲🇦 **Expanded Moroccan city list** with many major cities and regions.
- 🔎 **City search box** to quickly find the city you want from the dropdown.
- 🌍 **Global prayer search** through the “Find Your City” button, where users can enter a country code and city name to look up prayer times anywhere.
- 📅 **Monthly prayer schedule** displayed in a clean table.
- 💡 Click on any day to open full **prayer details** in a popup.
- 🎯 Today's date is highlighted for easier reading.
- ⚡ Real-time API fetching using **Axios**.
- 💻 Built with **Bootstrap 5** for a responsive and modern interface.
- 🎨 Smooth styling and visual feedback for a better experience.

## 🗺️ API Source

This app uses the **Aladhan Prayer Times API** for prayer schedules:

- `https://api.aladhan.com/v1/calendarByCity`

It requests prayer times by sending the selected city and country code, then displays the monthly schedule in the table.

> The older Render-hosted endpoint was removed from the app because it was unreliable and caused browser-side CORS issues.
